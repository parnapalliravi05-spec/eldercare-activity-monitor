01 • PROJECT OVERVIEW

What the system does

The prototype observes simple daily activity signals and compares them with expected activity. It is designed to highlight unusual inactivity so a caregiver can check on the person.

01

Passive sensing

Movement, door and appliance events can be collected without requiring continuous manual input.

02

Activity analysis

Python-based processing converts sensor activity into an understandable risk indication.

03

Caregiver alert

When activity is substantially below the learned baseline, the interface displays an alert.

Planned physical integration

ESP32 DevKit V1

Microcontroller with Wi-Fi for collecting and transmitting sensor events.

HC-SR501 PIR

Represents door open/close activity for the activity timeline.

LED indicators
