01 • PROJECT OVERVIEW

Passive activity monitoring

The system uses activity information such as movement, door events and appliance usage to estimate an activity-risk level for an elderly person living alone.

01

Activity collection

Movement, door and appliance events can be collected through passive monitoring.

02

Activity analysis

The collected activity information is processed to identify changes from normal activity.

03

Caregiver awareness

A higher-risk activity pattern can be highlighted so that a caregiver can check on the person.
